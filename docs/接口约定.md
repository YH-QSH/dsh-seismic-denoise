## 4. teammate-formats：`engine/formats/`

### 必须导出（`engine/formats/__init__.py` 再导出一次）

```python
detect_format(path: str | Path) -> str

read_any(path: str | Path, max_traces: int | None = None) -> SeismicDataset

# 解析 SEG-Y 240 字节道头，返回常见字段（见下）

analyze_binary(path: str | Path, max_bytes: int = 2_000_000) -> dict
# 任意二进制初判：魔数、文件大小、候选 ns/dt/fmt/端序、置信度、建议
```

### SEG-Y 要求
- 支持标准 3200 字节文本头 + 400 字节二进制头 + 扩展文本头；支持变长道。
- 样本格式 1=IBM float、2=int32、3=int16、5=IEEE float、8=int8；大小端自动判别。
- 道头至少解析这些常用字段（1-based byte）：
  `trace_seq(1,4)`、`energy_source(9,4)`、`ensemble(21,4)`、`cdp(21,4)`、`inline(189,4)`、`crossline(193,4)`、
  `shotpoint(17,4)`、`offset(37,4)`、`receiver_elev(41,4)`、`source_elev(45,4)`、`source_depth(49,4)`、
  `receiver_depth(53,4)`、`scalar(71,2)`、`ns(115,2)`、`dt(117,2)`、`source_x(73,4)`、`source_y(77,4)`、
  `cdp_x(181,4)`、`cdp_y(185,4)`、`coord_unit(89,2)`。
  注意：现有 `vsdn2/sgy.py` 的常量是 **0-based**，移植时统一成 1-based 对外，内部随意。
- `dt` 优先取道头（μs→秒），不合理再用二进制头 3217 字节处；`dz` 用 `receiver_elev` 逐道差估计（>100 视为厘米；异常则用 `receiver_depth`，再不行 `None`）。
- 文本头解码：EBCDIC/ASCII 自动尝试。
- `confidence`：0–1，文本头/二进制头/道头/道数一致性综合；每条警告写进 `warnings`。
- 大文件：`max_traces` 截断并警告；默认不截断。内存峰值控制在数据本身 3 倍以内。

### MAT / NPY / NPZ / HDF5 / RAW
- MAT：`scipy.io.loadmat`；识别嵌套 `data`/`header`/`trace_headers`（参考 `vsdn2/sgy.py:load_seismic_mat`）；找不到 2D 数值矩阵就遍历变量选最像地震数据的（维度 ≥2、有限值多、非全零）。
- NPY/NPZ：直接取最大 2D 数组；`npz` 里可带 `dt`/`dz`。
- HDF5：`h5py` 递归找最大 2D 数据集；读取 `dt`/`dz` 属性（`dt`/`sample_interval`/`dz`/`spacing`）。
- RAW：没有头时，按候选 `(dtype, endian, ns)` 扫描，用“相邻道相似度 + 振幅分布 + 无长零段”打分，最高分作为结果；`confidence` 不超过 0.45，并明确警告“按裸二进制推断，建议提供 ns/dt”。
- 所有格式统一把 NaN/Inf 交给 `utils.clean_array` 处理，警告合并进 `dataset.warnings`。

### 自测
- 用真实 Whataroa 文件读一遍，断言 `ns=4000, ntr≈436`（以实际为准）、`dt≈0.001`、`dz≈2.05`、`format` 识别为 segy。
- 生成一个合成 SEG-Y（IBM float + IEEE float 各一），写读回环，误差 <1e-5。
- 生成 `.npy`/`.npz`/`.mat` 小样本，`read_any` 都能读。
- 用 `python -m pytest tests/test_formats.py -q` 通过（pytest 若未装，用 `python tests/test_formats.py` 直接跑）。

## 5. teammate-denoise：`engine/methods/` + `engine/quality/`

### `engine/methods/classical.py`

```python
def available_methods() -> dict[str, dict]
# key -> {"name","description","targets":[...],"params":{...默认值...},"params_schema":{...}}

def run_method(key: str, data: np.ndarray, dt: float, dz: float | None,
               params: dict | None = None) -> tuple[np.ndarray, dict]
# 返回 (去噪后 float32, info{"notes","params_used","warnings"})；不修改入参。
```

必须实现（key 固定）：
`bandpass`、`notch`（50/60Hz 及谐波可配）、`despike`、`median`、`fk`、`fx_decon`、`svd`、`spectral_sub`、`wavelet`。
- `fk`：复用/改造 `vsdn2/baselines.py:fk_filter`，参数 `vmin`、`taper`、`reject_slow`。
- `fx_decon`：f-x 域复数 Wiener 预测滤波（常规地震去随机噪声），窗口可配。
- `svd`：局部窗口 SVD 秩截断（沿空间/时间），窗口与秩可配。
- `spectral_sub`：STFT 谱减，噪声谱从每道低能量段估计，过减因子/下限可配。
- 所有方法做输入校验；`dt` 无效时抛 ValueError；`dz` 为 None 时 fk 用相对慢度或跳过并警告。
- 参数默认值要保守，确保不会把有效信号削光。

### `engine/methods/cnn.py`

```python
def cnn_available() -> bool
def run_cnn(data, dt, dz, params: dict | None = None) -> tuple[np.ndarray, dict]
```
- 权重固定路径 `engine/assets/cnnv2/权重/`，`torch.load(..., map_location=..., weights_only=False)`。
- 复用 `engine/assets/cnnv2/vsdn2/` 的 `config/models/tiling`；模型结构：`M.建模型(cfg.模型, "分离")`、分类器同法。
- 先跑分类器得 5 类概率（`分类剖面`），再按 `w=(prob>0.5)*prob` 门控分离网络，`按类别重建`。
- 参数：`alpha`（默认 0.65，0–1）、`gate`（默认 True）、`device`（"auto"/"cpu"/"cuda"）、`resample`（默认 False；True 时用 `utils.resample_to` 到 2ms/5m 再回来）、`max_traces`（大数组分块）。
- 任何异常（CUDA 不可用、权重缺失、OOM）都要捕获，降级 CPU 或抛 `RuntimeError`，并在 info 里说明。
- `info` 必须含：`class_probs`（5 类平均概率）、`gating_weights`、`alpha`、`device`、`energy_ratio`。

### `engine/methods/planner.py`

```python
def plan(assessment: SourceAssessment, cfg: dict) -> list[MethodSpec]
def refine(assessment: SourceAssessment, history: list[MethodResult], cfg: dict) -> list[MethodSpec]
```
- 规则：按 `assessment.noise_types` 排序命中；面波→fk/bandpass/median；随机→fx_decon/spectral_sub/cnn；工频→notch；散射绕射→fk/svd/cnn；折射→fk/median；未知→保守 bandpass + cnn。
- 第一个方案给“主方法”，后续给备选（不同强度/参数）；`refine` 要避开已失败的方法，并根据失败原因调整（过削→降 alpha/加保护带；不够→加强度/换方法）。
- 最多返回 4 个单方法/轮；阶段三起 `plan()` 会再追加最多 2 条组合候选（`key="combo"`，`params={"chain":[{"key":..., "params":...}, ...]}`），`refine` 只重试单方法调参。
- `allow_cnn=False` 时组合链不得含 `cnn`。
- 不调用外部模块，只 import `engine.model`。

### `engine/quality/metrics.py`

```python
def blind_snr(data, dt, dz=None) -> dict
# {"snr_db":float, "signal_db":float, "noise_db":float, "reliable":bool, "method":str}

def evaluate(noisy: np.ndarray, denoised: np.ndarray, dt: float,
             dz: float | None = None, reference: np.ndarray | None = None) -> QualityMetrics
```
- 盲信噪比：局部窗口（如 256ms）能量分位数 + 高频段噪声估计；不要假设有参考。
- `reference` 存在时再算 `reference_*`（相对参考的 SNR 增益）。
- `signal_leakage`：被去除分量与去噪结果的局部相关（越高说明越可能削到信号）。
- `spectrum_corr`：5–80Hz 信号带内振幅谱相关。
- `coherence_residual`：残差与去噪结果的分窗相关。
- `energy_ratio`、`clip_ratio`、`local_snr_gain_db`。
- 全用 float，不用 NaN；无法计算给 `None` 并在 `extra["notes"]` 说明。

### `engine/quality/gate.py`

```python
def industry_gate(metrics: QualityMetrics, assessment: SourceAssessment | None = None,
                  cfg: dict | None = None) -> GateResult
def gate_confidence(metrics: QualityMetrics, gate: GateResult,
                    assessment: SourceAssessment | None = None) -> float
```
默认阈值（可在 `cfg["gate"]` 覆盖）：
- `snr_gain_db >= 3.0`（硬）
- `energy_ratio` 在 `[0.60, 1.05]`
- `signal_leakage <= 0.40`（有纯净参考时放宽到 0.45）
- `reference_gain_db >= 0.5`（仅有参考时启用，硬）
- `spectrum_corr >= 0.80`
- `weak_signal_ratio >= 0.85`（视觉/弱区保真；不可用时跳过）
- `clip_ratio <= 1e-3`
- `snr_out_db >= 10.0`（盲估计 `reliable=False` 时降为软检查）
- 干净数据（`assessment.needs_denoise=False`）不走去噪门禁。
`checks` 每项都要有 `name/value/threshold/passed/note`；`failures` 写人话；`advice` 给下一步建议（换方法/降强度/检查参考）。
`score` 0–100；`confidence` 0–1（指标可信度 × 门禁余量 × 来源匹配置信度）。

### `engine/methods/runner.py`

```python
def run_attempts(ds: SeismicDataset, specs: list[MethodSpec], cfg: dict,
                 reference: np.ndarray | None = None,
                 log=print) -> list[MethodResult]
def pick_best(results: list[MethodResult]) -> MethodResult | None
```
- 依次执行；每步 `evaluate` + `industry_gate`；`gate_confidence` 写进 `GateResult.confidence`。
- 单个方法异常不中断，记录 `warnings`/`notes` 后继续。
- `pick_best`：优先通过门禁的；有参考时先按 `reference_gain_db` 降序，再按 `gate.score`、置信度排序；无参考按 score。
- 运行时间记录到 `runtime_s`；不写文件（流水线负责保存）。

### 自测
- 合成：线性同相轴 + 高斯噪声 + 50Hz 工频 + 低速面波；每个方法输出有限、shape 不变。
- 真实 Whataroa：至少 `bandpass`、`fk`、`cnn` 能跑通；记录耗时与指标。
- 门禁对“原样返回”应判失败（增益≈0），对“强噪声→去噪”应判通过。

## 9. 判断层（0.1.1，框架升级阶段）

判断层是**只读**调用引擎，不生成报告、不写成果目录；用于回答“这次去噪到底能不能验收”。入口：

```python
from engine.judgment import run_case

case = run_case(
    input_path,
    reference_path=None,   # 有纯净参考时传入，用于真实增益/UQ
    cfg=None,              # 可覆盖 config.DEFAULT_CONFIG
    max_methods=4,
    allow_cnn=False,
)
case.to_dict()
```

返回 `CaseResult`（`engine/judgment/orchestrator.py`）：

- `mode`：`denoise` | `clean`
- `card`：`CaseCard`，来源/噪声/采样/坏道率/SNR/可靠度/推荐方法等
- `candidates`：规划出的候选方法/组合（`MethodSpec.to_info()` 列表）
- `attempts`：实际执行记录（含失败尝试）
- `best_method`：最佳方法名（可能为 `None`）
- `uq`：`UQReport`，`available/reliable/mean/std/lo/hi/n/n_methods`
- `evidence`：`Evidence`，`decision`（`accept` / `conditional` / `reject` / `abstain`）、`flags`、`reasons`、`notes`、`confidence`
- `notes`：案例级提示

决策约束：

- `accept`：有参考且门禁通过、`reference_gain_db ≥ 0.5`、证据无硬失败；无参考不允许 `accept`。
- `conditional`：可去噪但证据不足（如无参考、UQ 样本不足）。
- `reject`：门禁失败或参考增益不足。
- `abstain`：OOD 分数异常或主动拒答。

CLI：

```powershell
python -m engine.cli judge --input "数据.sgy" --reference "干净参考.sgy" --max-methods 4 --no-cnn --json-out "判断.json"
```

对应 DSH 工具：`seismic_judge`（参数 `path`、`reference`、`maxMethods`、`allowCnn`）。
